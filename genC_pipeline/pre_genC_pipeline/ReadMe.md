# Complete Unified Analysis Pipeline for sedaDNA Habitat Classification

## Description

This R script provides a **comprehensive end-to-end analysis pipeline** for metagenomic sedimentary ancient DNA (sedaDNA) data, focusing on the classification of species (Bacteria, Archaea, and Eukaryota) into aquatic and terrestrial habitats across sediment cores.

It automatically loads relevant `.RData` files, links taxonomic data to habitat databases, performs classification, and calculates habitat-specific read abundances over time. The script can be run from start to finish in a single execution.

---

## Directory Structure

### Input data:
- `*.RData` files for each sediment core (deriving from the HOLI pipeline [`Yong-Weiss-et-al.-2025-HOLI`](../../Yong-Weiss-et-al.-2025-HOLI) )
- Habitat classification CSV files for Bacteria and Archaea
- Eukaryota database (`final_results_eukaryota_excel-4.xlsx`)
- Plant family classification table (`Plant_Family_Type.csv`)

### Output folders:
- Prokaryote classification: `1_Prokaryote_Classification_Output/`
- Final results and time series: `2_Final_Analysis_Output/`

---

## Script Sections

### 1. Configuration
- Load required R packages
- Define base paths (`BASE_PATH`)
- Load paths for core data and habitat classification tables

### 2. Helper Functions
- Core-wise data pre-processing
- Habitat assignment for eukaryotes (with specific rules for plants and animals)
- Rule-based decision logic for habitat classification
- Prokaryote classification using read distribution and isolation metadata
- Calculation of habitat proportions over time (e.g., by thousand years)

---

## Analysis Overview

For each sediment core, the following steps are performed:

1. Load and filter MergedData files
2. Link taxa with habitat metadata
3. Classify each taxon as aquatic, terrestrial, both, or unclassified
4. Calculate the relative proportion of aquatic vs. terrestrial reads over time
5. Export all outputs as `.csv` files

# PART 2 
## Overview

The pipeline performs the following key steps:

- Reads DNA concentration and sequencing metadata from CSV files
- Reads habitat composition percentages for different taxa groups
- Merges these datasets on common keys (`Number` and `Age`)
- Converts specified columns to numeric data types to ensure proper calculations
- Calculates derived variables such as starting DNA amounts, dry weight normalization, sediment bulk density, and carbon content
- Creates additional columns representing DNA amounts weighted by habitat percentage contributions
- Saves the processed and augmented dataset as a CSV file for downstream analysis

---

## Functions in the Script

- **`load_csv()`**: Loads a CSV file with minimal column name repair and optional suppression of column type messages.
- **`convert_to_numeric()`**: Safely converts selected columns to numeric, handling missing columns gracefully.
- **`compute_derived_metrics()`**: Calculates key derived DNA and sediment metrics using relevant input columns.
- **`create_start_wt_columns()`**: Generates new columns multiplying habitat percentage columns by the normalized starting DNA weight.

---

## Input Data

- **DNA information file**: Contains raw measurements such as DNA concentration, molecular weight, dilution factors, sequencing read lengths, library concentrations, water content, sedimentation rates, bulk density, and total organic carbon.
- **Habitat percentage file**: Contains percentage values for aquatic, terrestrial, and unclassified fractions across multiple taxa groups including Bacteria, Archaea, Fungi, Viridiplantae, Metazoa, Viruses, and aquatic algae.
